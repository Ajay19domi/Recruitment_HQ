RECRUITMENT HQ

Connect your workspace

1. Create the database

In your Supabase project, open SQL Editor → New query. Download the setup SQL below, copy its contents into the editor and run once.

2. Create your login

Open Authentication → Users → Add user → Create new user. Enter your email and a strong password. Confirm the email using the dashboard option if available. Keep your password private.

3. Activate yourself as Super Admin

Run this in a separate SQL Editor query, replacing YOUR_EMAIL with the email you just used:

update public.profiles
set role='admin', active=true, name='Ajay Prakashan'
where id=(select id from auth.users where email='YOUR_EMAIL');

4. Sign in

Return to the dashboard and use your new email and password. The live workspace starts empty. Demo records are not imported.

5. Add the team

Create Shaji and the recruiter in Authentication → Users. Then open dashboard Settings, activate their accounts and assign Manager / Recruiter roles. Candidates must be assigned to the recruiter to be visible to them.

The current hosting preview remains owner-private. Sharing access with your team needs a separate hosting-access change. CV uploads and in-app invitations are pending.
